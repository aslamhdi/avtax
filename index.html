🔁 Transfer Antar Rekening

💡 Transfer akan otomatis membuat jurnal kredit akun sumber dan debit akun tujuan.

📥 Import Mutasi Bank

💡 Import file mutasi bank dari CSV. Kolom yang dibutuhkan: tanggal, keterangan, debit, kredit, saldo

📥 Import Jurnal dari Excel

💡 Pastikan file Excel sesuai format. Klik "❓ Format Import" untuk melihat contoh format yang benar.

❓ Format Import Jurnal Excel / CSV

File harus memiliki kolom-kolom berikut (nama kolom harus sama persis):

Kolom Keterangan Contoh
tanggalTanggal transaksi2024-01-15
refNomor referensiJU-001
keteranganDeskripsi transaksiPenjualan tunai
akunKode akun COA1100
keterangan_barisDetail baris (opsional)Kas masuk
debitJumlah debit (angka)5000000
kreditJumlah kredit (angka)0
✅ Tips: Satu transaksi bisa punya banyak baris. Baris dengan ref yang sama digabung menjadi 1 entri jurnal.
⚠️ Catatan: Kode akun harus sesuai COA yang sudah ada di sistem.

📤 Backup Data

Simpan semua data ke file JSON di perangkat kamu. Simpan di tempat aman (Google Drive, WhatsApp ke diri sendiri, dll).

📥 Restore Data

Pulihkan data dari file backup JSON sebelumnya. Data saat ini akan ditimpa!

💡 Tips rutin: Backup minimal 1x seminggu. Beri nama file dengan tanggal, contoh: backup-akuntansi-2024-01-15.json

📋 Data Mentah (JSON)

Salin semua teks di bawah ini dan simpan di mana saja (Notes, Google Keep, dll) sebagai backup darurat.

📂 Saldo Awal Tahun Sebelumnya

Masukkan saldo awal per akun dari tahun buku sebelumnya atau dari sistem lama. Saldo ini akan diikutsertakan dalam perhitungan buku besar dan laporan keuangan.

💡 Tips: Akun Pendapatan & Beban juga bisa diberi saldo awal jika kamu mulai menggunakan aplikasi ini di tengah tahun buku berjalan (misalnya mulai Maret, isi saldo Jan-Feb di sini).
